# CloudCut

Playable build of CloudCut, a paper-cut balloon taxi game with three levels.

Play: https://konnie-lab.github.io/cloudcut/

Hold to rise, drag sideways to steer, release to descend. Keyboard: W/Up and A/D/Left/Right.
Choose DEFAULT, HARD or ARCADE in the bottom panel; the initial mode is DEFAULT.

Deliver five passengers. Avoid striking pedestrians with the basket. If someone falls into the water, settle nearby with an empty basket to rescue them before the slow rescue boat arrives. The timer records your completion time.

This repository contains the standalone production build only.
